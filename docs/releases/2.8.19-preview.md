# Notchloom 2.8.19 preview (319)

Notchloom brings music, files, focus and optional intelligence to the space around your Mac's notch. This is the first public preview installer of this fork.

## Download and install

- Download `Notchloom-2.8.19-Apple-Silicon.dmg` from this release, open it, and drag Notchloom into Applications.
- Apple Silicon only. The binary targets macOS 14.0 or later; release testing was on the developer's Apple Silicon Mac running macOS 26. Intel and older macOS runtime behavior have not been tested for this release.
- **Apple Development signed; not Developer ID signed or notarized.** macOS may block launch. A trusted distribution release requires the maintainer to configure Developer ID signing and notarization. This preview does not change Gatekeeper or include bypass commands.
- `SHA256SUMS.txt` identifies the installer and the matching source archive. The source also appears under this release's tag, licensed under GPL-3.0 with upstream attribution and third-party notices.
- This is a manual preview download. It is not offered through Sparkle automatic updates.

## Included features

- Now Playing with artwork, transport controls and lyrics when available.
- Overview with quick apps, Calendar, Focus Timer, optional Mirror, Today and Power usage.
- Drag-to-open File Shelf, native sharing and Convert with input-aware output choices.
- Intelligence conversations with follow-ups through a configured Shortcut or Gemini provider.
- Optional notification mirroring and system HUDs, subject to macOS permissions and supported visible banners.
- Power usage V2: battery ring, adaptive wattage, real 60-second history and a measurement-details popover. Unsupported hardware readings are omitted.

## Limits and setup

Some integrations require Accessibility, Calendar, Camera or Location permissions. Today uses your own Gemini API key and sends selected context only after consent. Apple Intelligence uses a configured Shortcut and requires a compatible system. Conversion formats depend on the input and installed engines; see `docs/conversion.md`. Power figures depend on hardware telemetry; see `docs/power-usage.md`.

The application retains the upstream bundle identifier, so it may share preferences and permission identity with Boring Notch. Quit Boring Notch before using Notchloom; this release does not erase existing preferences.
